How V4 learns: it maintains a curriculum state, chooses the next knowledge gap, researches public sources, asks the selected model to teach/explain, generates checks and troubleshooting exercises, stores the result locally, and uses previous records to choose the next cycle. It does not secretly rewrite its own code; that would be unsafe in a public static site. Instead it self-improves its learning plan, knowledge state and next actions.

No-key mode: WebLLM can run an open model in the browser when the device/browser supports WebGPU. On iPhone/Safari, larger local models can be memory-intensive, so the V4 local default is intentionally small. WebLLM documents browser/WebGPU inference, and its issue tracker contains reports of larger models crashing iOS Safari, so cloud mode is the practical route for stronger models.
