# Recursive AI Agent

A standalone, mobile-first recursive AI-agent playground. This repository is completely separate from the portfolio repository.

## Enable GitHub Pages

In this repository open **Settings → Pages**.
Under **Build and deployment**, choose **Deploy from a branch**.
Select **main** and **/(root)**, then **Save**.

After GitHub publishes it, the site will be:

https://sivashankarg.github.io/recursive-ai-agent/

## V1
- Recursive goal iterations
- Public internet research through Wikipedia
- Persistent browser memory with localStorage
- Stop, clear, and export controls
- No API keys stored in the repository
